## Панель сведений (UI/UX)

Сейчас «Информация» (пункт меню ПКМ, двойной клик в режиме просмотра) открывает боковую панель:
`src/ui/panels/InfoPanel.ts`, содержимое — `src/core/describe.ts`, вызов — `GraphApp#openInfo`.
Это плоский список «подпись — текст» без картинки, цветов, иконок и действий.

### Содержимое панели

- [ ] **Шапка с портретом.** Миниатюра изображения узла (то же, что на графе, с учётом
  `imageSource`/`imageFit`), рядом имя, тип и роль. Скрытый узел у игрока — заглушка
  `assets/placeholder-npc.png`, без настоящей картинки. У связи — миниатюры двух концов со
  стрелкой/линией между ними, у фракции — плашка её цвета.
- [ ] **Порядок блоков по важности.** Описание → заметки → фракции/состояния → связи. Сейчас
  описание идёт после длинного списка связей.
- [ ] **Связи — кликабельным списком.** Каждая строка — кнопка: клик центрирует вид на узле и
  показывает в панели его сведения (как `#showSearchTarget`), наведение подсвечивает узел и связь
  на графе. Перед строкой — полоска цвета и штриха типа связи (`RelationshipType.color`, `dash`).
  У карточки связи кликабельны оба конца.
- [ ] **Связи: группировка.** Больше ~8 связей — группами по типу связи (заголовок с цветом и
  счётчиком, группы сворачиваются). Входящие/исходящие — иконкой, а не только `→`/`←`.
- [ ] **Фракции и состояния — чипами.** Фракция — чип с кружком её цвета, основная — иконкой или
  жирным вместо текста «(основная)»; клик по чипу показывает сведения фракции. Состояние — чип с
  его иконкой Font Awesome, как в панели узла. Участники фракции — кликабельным списком, как связи.
- [ ] **Видимость — значком в шапке** (GM): `fa-eye-slash` «Скрыт», `fa-user-lock` «Только GM», с
  подсказкой. Сейчас строка «Видимость» теряется в конце.
- [ ] **Убрать «Размер ×1.0».** Для просмотра это служебное значение; у скрытого узла у игрока
  карточка из-за него выглядит «пустой, но с цифрой». Размер виден в панели редактирования.
- [ ] **Пустое состояние.** Узел без роли, описания, фракций и связей — подсказка «Сведений нет»
  (у GM — как заполнить), а не панель из одного заголовка.

### Читаемость

Панель редактирования — 300px и 13px: для полей формы хватает, для прозы узко (~40 знаков в
строке при удобных 50–75) и мелко; к тому же панель перекрывает правую часть графа.

- [ ] **Ширина панели сведений и изменение ширины.** По умолчанию 360–400px; левый край
  перетаскивается, ширина запоминается в `localStorage` (чтение/запись в try/catch, без него —
  ширина по умолчанию). Ограничить снизу (~280px) и сверху (доля окна графа), чтобы в маленьком
  окне и popout граф оставался видимым.
- [ ] **Типографика текста.** Описание и заметки — 14px, `line-height: 1.5`, абзацы с отступом;
  подписи блоков — как сейчас, мелким приглушённым.
- [ ] **Узел не прячется под панелью.** При открытии сведений и при переходе к другому элементу —
  если элемент под панелью или у её края, сдвинуть вид; центрировать по видимой части графа
  (ширина окна минус панель), а не по всему окну. То же для «Показать на графе» и клика по связи.
- [ ] **Шапка закреплена.** Портрет и имя — `position: sticky` вверху тела панели: при прокрутке
  видно, чьи это сведения.
- [ ] **Сворачиваемые блоки.** Описание, заметки, связи, фракции — секциями с заголовком-кнопкой
  (`aria-expanded`); какие свёрнуты — запоминать в `localStorage` (как ширину).
- [ ] **«Развернуть» для длинного текста.** У описания и заметок длиннее ~15 строк — кнопка,
  открывающая текст в отдельном окне Foundry (`DialogV2`) нормальной ширины, только для чтения.

### Действия

- [ ] **Подвал с действиями** (те же права, что в меню ПКМ): «Изменить» — в режиме редактирования
  и при `canEditNode`, переключает панель на форму редактирования на месте, после сохранения или
  отмены — обратно к сведениям; «Лист актёра» (GM); «Выбрать область» (фракция); «Показать на
  графе» — центрировать вид на элементе.

### Доступность

- [ ] **Семантика и фокус.** Панель — `role="dialog"` (немодальный), `aria-labelledby` на заголовок;
  при открытии фокус в панель, при закрытии — обратно. Поля — `<dl>`/`<dt>`/`<dd>`. Связи и чипы
  доступны с `Tab`, `Enter` — переход.
- [ ] **Открытие с клавиатуры.** `Enter` (или `I`) на выделенном узле/связи открывает сведения.
