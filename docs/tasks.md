# Tasks

Планы на следующие версии. Сделанная задача остаётся здесь с отметкой `[x]`, пока её работа
не подтверждена; после подтверждения она переносится в [CHANGELOG.md](../CHANGELOG.md).

Формат: `[ ]` не начато · `[~]` в работе · `[x]` сделано, ждёт проверки · `[!]` заблокировано.

## UI: общее

Доступность:
- [ ] Ползунок масштаба: вернуть видимый фокус — `.frg-zoom input.frg-zoom-slider:focus`
  убирает `outline`/`box-shadow`; нужен `:focus-visible`.
- [ ] Контекстное меню с клавиатуры: `role="menu"`/`menuitem`, фокус в меню при открытии,
  стрелки вверх/вниз, `Enter`.
- [ ] Вкладки панелей (`addPanelTabs`): `role="tablist"`/`tab`/`tabpanel`, `aria-selected`.
- [ ] Минимальный размер текста 12px: подписи полей и карточки информации (11px), процент
  масштаба (10px).
- [ ] Цвет панели инструментов (`toolbarColor`): контраст кнопок не гарантирован — подбирать цвет
  текста/иконок под яркость фона (светлый/тёмный).

Формы (`src/ui/panels/form.ts`, для всех панелей сразу):
- [ ] `field()`: подпись связана только с первым полем строки — у остальных полей
  (`colorField`, строки с кнопками, X/Y) `aria-label`.
- [ ] `hint()` связать с полем через `aria-describedby`.
- [ ] `colorField`: пустое значение показывать не чёрным, а цветом по умолчанию / «не задан».
- [ ] Панель узла: «Выравнивание» картинки — сетка 3×3 с иконками, «Вписывание» — сегменты с
  иконками вместо `<select>`.

Стиль:
- [ ] Цвета панелей и всплывающих элементов — CSS-переменные `--frg-*` в одном месте вместо ~30
  hex в `module.css`; связать со светлой/тёмной темой Foundry 13.
- [ ] Кнопка закрытия панели: иконка `fa-xmark` вместо символа «×» и `aria-label`.
- [ ] Знак режима редактирования на самом графе (рамка или плашка «Редактирование»), а не только
  жёлтая кнопка на панели.

Взаимодействие:
- [ ] Ползунок масштаба не прятать под боковой панелью — сдвигать влево на её ширину.
- [ ] Отмена/повтор скрывать вне режима редактирования (как кнопку фона).
- [ ] Шпаргалка управления: кнопка «?» на панели инструментов; в контекстном меню — клавиши рядом
  с пунктами (`Delete`, `S`).
- [ ] Пустой граф: подсказка «ПКМ — добавить узел», пока узлов нет.
- [ ] Поиск: placeholder в поле, стрелки по результатам, `Enter` — к первому совпадению.
- [ ] Карточка информации: не закрывать колесом, если прокрутка внутри неё.
