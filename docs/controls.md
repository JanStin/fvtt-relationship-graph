# Управление графом

Реализация — `src/ui/interaction.ts` (жесты), `src/ui/overlays.ts` (меню и карточка информации).

## Мышь

| Действие | Что делает |
| --- | --- |
| Колесо | Масштаб вида |
| Зажатое колесо + движение | Перемещение по виду |
| `Alt` + колесо | Изменение размера выделенных узлов (пропорции между ними сохраняются). Если ничего не выделено — узла под курсором |
| ЛКМ по узлу | Выделить узел; с движением — перетащить его (если выделено несколько — всю группу) |
| ЛКМ мимо узла + движение | Перемещение по виду — в том числе если клик пришёлся по области фракции |
| ЛКМ по пустому месту (без движения) | Снять выделение |
| `Shift` + ЛКМ по узлу | Добавить узел к выделению / убрать из него |
| `Shift` + ЛКМ + движение | Рамка выделения |
| `Ctrl` + ЛКМ + движение | Перемещение по виду независимо от того, что под курсором |
| `Alt` + ЛКМ по области | Выбрать область: выделяются все узлы фракции (`Shift` — добавить к текущему выделению) |
| `S` + ЛКМ по узлу | Быстрое создание связи. Если выделен один другой узел — связь сразу от него к нажатому. Иначе нажатый узел — начало, затем клик по второму узлу (с `S` или без) |
| Двойной клик ЛКМ по узлу/области | Карточка информации |
| Двойной клик ЛКМ по связи | Панель редактирования связи |
| ПКМ | Контекстное меню |

## Клавиатура

| Клавиша | Что делает |
| --- | --- |
| `Esc` | Закрыть меню/карточку; снять выделение (пока курсор над графом) |

## Контекстное меню

- **Узел:** «Информация», «Редактировать» (только GM), «Создать связь», «Открыть лист актёра» (если узел привязан к актёру), «Сбросить размер».
- **Связь:** «Редактировать связь», «Удалить связь» (только GM).
- **Область:** «Информация», «Выбрать область», «Редактировать фракцию» (только GM).
- **Область и пустое место** (только GM): «Добавить узел», «Фракции…», «Типы связей…», «Состояния…».
- **Всегда:** «Показать весь граф», «Снять выделение» (если что-то выделено).

## Создание узлов (только GM) и связей

- **Узел:** ПКМ по пустому месту → «Добавить узел». Узел появляется в точке клика, сразу
  открывается его панель. Если кликнуть по области фракции, узел сразу войдёт в эту фракцию.
- **Связь:** ПКМ по узлу → «Создать связь» или `S` + ЛКМ по узлу, затем клик по второму узлу —
  открывается панель «Новая связь». Пока идёт выбор, сверху висит подсказка, узел-источник обведён
  голубым. `Esc` или ПКМ — отмена.
- Новая связь появляется на графе только после «Сохранить» и только если в ней что-то заполнено
  (подпись, тип, направленность или «только GM»). Пустая связь не создаётся.
- Тип связи «Романтическая» (розовый) есть в любом графе; если его удалить, он вернётся при
  следующем открытии графа.

## Примечания

- Размер узла: от ×0.3 до ×5.0, шаг 0.1.
- Область подсвечивается, когда выделены все её узлы. Выбранную область можно двигать
  целиком — перетаскиванием любого её узла.
- После перетаскивания и изменения размера узлы автоматически раздвигаются, чтобы не
  накладываться; результат сразу сохраняется.

## Панели редактирования (только GM)

Открываются справа в окне графа; одновременно открыта одна. «Сохранить» (или Enter в
однострочном поле) записывает изменения и перерисовывает граф, «×» закрывает без сохранения.

- **Узел:** тип (актёр / без актёра / просто изображение) и привязка к актёру, имя, изображение (кнопка «Обзор» — штатный выбор файла Foundry), роль, фракции
  (галочка — узел состоит во фракции, отметка справа — основная фракция, она рисуется
  областью; остальные — ромбиками на узле), размер, состояния (чекбоксы по справочнику), описание, заметки для игроков, заметки GM; «Удалить узел»
  удаляет его вместе со связями. У узла, привязанного к актёру, имя и изображение берутся
  из актёра и в панели заблокированы.
- **Связь:** подпись, тип, направленность (стрелка), «видна только GM» (рисуется пунктиром,
  игрокам не показывается); «Удалить связь».
- **Фракции** (ПКМ → «Фракции…»): список всех фракций с числом узлов; клик по строке открывает
  форму фракции, «Создать фракцию» — форму новой. Фракция, которая ни у одного узла не основная,
  на графе не рисуется — она доступна только из этого списка.
- **Фракция:** название, цвет, описание; «Удалить фракцию» убирает её у всех узлов (сами узлы
  остаются; если фракция была у узла основной, основной становится следующая его фракция).
- **Состояния** (ПКМ → «Состояния…»): справочник состояний с числом узлов. Встроенные
  (`Мёртв`, `Даёт задание`, `В плену`, `Пропал`) не редактируются; «Создать состояние» добавляет своё.
- **Состояние:** название и иконка — класс Font Awesome (например `fa-skull`; рядом с полем
  предпросмотр). «Удалить состояние» снимает его со всех узлов.
- **Типы связей** (ПКМ → «Типы связей…»): список типов с числом связей; форма типа — название,
  цвет, стиль линии (сплошная, пунктир, длинный пунктир, точки). «Удалить тип связи» оставляет
  связи, но без типа.

## Что доступно игрокам

Игрок может двигать узлы, менять их размер, создавать и редактировать связи. В панели связи у
игрока нет флажка «Видна только GM» и кнопки удаления; связи «только GM» игрок не видит вовсе.
Узлы, фракции, состояния и типы связей правит только GM.

Право записи игрокам открывается автоматически, когда граф открывает GM (журнал «Relationship
Graph Data» получает владельцев «все»).
