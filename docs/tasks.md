## Идеи

- [ ] Версия схемы данных в хранилище (`schemaVersion` во флаге журнала) — чтобы будущие
  несовместимые изменения модели мигрировать явно, а не только `ensure*`-функциями.
- [ ] Хранение GM-данных отдельно от общего журнала (запись через GM по сокету) — чтобы скрытые
  данные нельзя было прочитать через консоль (см. docs/architecture.md, R2).
