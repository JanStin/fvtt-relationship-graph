# Tasks

Планы на следующие версии. Сделанная задача остаётся здесь с отметкой `[x]`, пока её работа
не подтверждена; после подтверждения она переносится в [CHANGELOG.md](../CHANGELOG.md).

Формат: `[ ]` не начато · `[~]` в работе · `[x]` сделано, ждёт проверки · `[!]` заблокировано.

---

## Идеи

- [ ] Версия схемы данных в хранилище (`schemaVersion` во флаге журнала) — чтобы будущие
  несовместимые изменения модели мигрировать явно, а не только `ensure*`-функциями.
- [ ] Хранение GM-данных отдельно от общего журнала (запись через GM по сокету) — чтобы скрытые
  данные нельзя было прочитать через консоль (см. docs/architecture.md, R2).
- [ ] Теория: у графа прекрасно перекликаются баблы фракции. Можно попробовать, как налепление нескольких баблов на один узел вместо отображения ромбиков фракций.
