## Панель сведений (UI/UX)

Сейчас «Информация» (пункт меню ПКМ, двойной клик в режиме просмотра) открывает боковую панель:
`src/ui/panels/InfoPanel.ts`, содержимое — `src/core/describe.ts`, вызов — `GraphApp#openInfo`.
В шапке — картинка, имя, тип, роль и значок видимости; тело — блоки (текст, чипы фракций и
состояний, кликабельные связи с группировкой по типу).

### Читаемость

Панель редактирования — 300px и 13px: для полей формы хватает, для прозы узко (~40 знаков в
строке при удобных 50–75) и мелко; к тому же панель перекрывает правую часть графа.

- [ ] **Ширина панели сведений и изменение ширины.** По умолчанию 360–400px; левый край
  перетаскивается, ширина запоминается в `localStorage` (чтение/запись в try/catch, без него —
  ширина по умолчанию). Ограничить снизу (~280px) и сверху (доля окна графа), чтобы в маленьком
  окне и popout граф оставался видимым.
- [ ] **Типографика текста.** Описание и заметки — 14px, `line-height: 1.5`, абзацы с отступом;
  подписи блоков — как сейчас, мелким приглушённым.
- [ ] **Узел не прячется под панелью.** При открытии сведений и при переходе к другому элементу —
  если элемент под панелью или у её края, сдвинуть вид; центрировать по видимой части графа
  (ширина окна минус панель), а не по всему окну. То же для «Показать на графе» и клика по связи.
- [ ] **Шапка закреплена.** Портрет и имя — `position: sticky` вверху тела панели: при прокрутке
  видно, чьи это сведения.
- [ ] **Сворачиваемые блоки.** Описание, заметки, связи, фракции — секциями с заголовком-кнопкой
  (`aria-expanded`); какие свёрнуты — запоминать в `localStorage` (как ширину).
- [ ] **«Развернуть» для длинного текста.** У описания и заметок длиннее ~15 строк — кнопка,
  открывающая текст в отдельном окне Foundry (`DialogV2`) нормальной ширины, только для чтения.

## Узлы

- [ ] **Закрепление картинки узла с актёром.** Флажок «Закрепить изображение» у узла с актёром
  (вкладка «Вид» панели узла, рядом с «Изображение актёра»): закреплена — картинка узла больше не
  меняется вслед за портретом/токеном актёра (остаётся та, что была при закреплении); снят —
  берётся из актёра, как сейчас. Своя картинка при закреплении не ставится — поле остаётся
  заблокированным. Имя по-прежнему всегда из актёра.
  - Модель: поле узла `imagePinned?: boolean`; нет поля (старые графы) — не закреплено. Экспорт/
    импорт своего формата — с полем (`docs/graph-json-format.md`); FANG — не закреплено.
  - `syncNodeWithActor` не трогает `img` закреплённого узла. Смена «Изображение актёра»
    (портрет/токен) в панели у закреплённого узла — явное действие: картинка берётся заново.
  - «Настройки графа»: флажок «Закреплять изображение новых узлов» (поле фона графа, по умолчанию
    снят) — с каким значением флажка создаётся узел и привязывается актёр. Рядом кнопки
    «Закрепить у всех» / «Открепить у всех» — один шаг истории, `Ctrl` + `Z` отменяет.
  - Живое обновление: хук `updateActor` (смена `img`, `name`, картинки токена) у всех, у кого граф
    открыт, — перерисовка с сохранением вида, выделения и открытой панели, как при чужом
    изменении графа; у закреплённых узлов меняется только имя. Ничего не сохраняется — актёр и так
    подтягивается при каждой загрузке.
  - Если этот клиент редактирует и открыта форма (узел, связь, фракция, настройки) — перерисовку
    не делать, чтобы не потерять несохранённый ввод: отложить до закрытия формы или сохранения
    (`#commit` и так перерисует). Поиск, списки и сведения — перерисовывать сразу.

## Справочники

- [ ] **Ручной порядок фракций, типов связей и состояний.** В списках справочников (GM, режим
  редактирования) у строки — кнопки ↑/↓; шаг истории, `Ctrl` + `Z` отменяет. Исходный порядок —
  порядок создания (как сейчас).
  - Фракции и типы связей: порядок — порядок массивов в данных, перестановка меняет массив.
  - Состояния: встроенные двигаются наравне со своими — нужно новое поле графа
    `conditionOrder?: string[]` (id встроенных и своих). Нет поля или id в нём нет — встроенные
    первыми, затем свои по порядку создания; удалённые id пропускаются. Экспорт/импорт своего
    формата — с полем.
  - Где действует порядок: списки справочников, выбор фракций в панели узла, выбор состояний в
    панели узла, выпадающий список типа в панели связи, группы связей, чипы фракций и состояний в
    сведениях (сейчас чипы — в порядке, в каком их отметили у узла). В поиске — нет.
